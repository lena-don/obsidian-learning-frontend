**CommonJS (CJS)** — это ==формат модулей для языка [JavaScript](https://blog.skillfactory.ru/glossary/javascript/), который используется для подключения кода из одних файлов в другие==. 

Главные особенности

- **Синхронная загрузка:** файлы читаются последовательно прямо во время работы программы, что удобно для жесткого диска сервера, но плохо для браузеров.

- **Ключевые команды:** для импорта используется функция `require()`, а для экспорта — объект `module.exports`.

- **Динамичность:** экспортировать или импортировать данные можно внутри условий (`if`) или циклов. 

#### Пример кода
Экспорт из файла `math.js`:
```
function add(a, b) {
  return a + b;
}

module.exports = { add };
```

Импорт в файле `index.js`:
```
const { add } = require('./math');

console.log(add(2, 3)); // 5
```

### CommonJS vs [[ES-модули|ES Modules]]

| Критерий                   | CommonJS (CJS)                                   | ES Modules (ESM)                                                |
| -------------------------- | ------------------------------------------------ | --------------------------------------------------------------- |
| **Синтаксис экспорта**     | `module.exports` / `exports.name`                | `export` / `export default`                                     |
| **Синтаксис импорта**      | `require('module')`                              | `import { name } from 'module'`                                 |
| **Время загрузки**         | Синхронная (во время выполнения скрипта)         | Асинхронная (статический анализ до выполнения)                  |
| **Область применения**     | Исторический стандарт для [Node.js]              | Современный стандарт для браузеров и [Node.js]                  |
| **Поддержка Tree-shaking** | Нет (динамический импорт мешает оптимизации)     | Да (статическая структура позволяет удалять неиспользуемый код) |
| **Динамический импорт**    | Поддерживается по умолчанию (`require`)          | Поддерживается через функцию `import()`                         |
| **Контекст `this`**        | Равен `module.exports` на верхнем уровне файла   | Равен `undefined` на верхнем уровне файла                       |
| **Расширения файлов**      | `.js` (по умолчанию в старом Node.js) или `.cjs` | `.js` (при `type: "module"`) или `.mjs`                         |
