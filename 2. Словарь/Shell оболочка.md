**Shell** (в переводе с английского — «оболочка») в программировании и операционных системах — это ==командный интерпретатор, который служит прослойкой между пользователем (или скриптом) и ядром операционной системы==. 

Инфа  на [Хекслет](https://ru.hexlet.io/blog/posts/shell-chto-eto-takoe-i-zachem-on-nuzhen).

См также: [[CLI интерфейс командной строки]]

По умолчанию используется **22-й порт**.

#### Главные функции Shell
- **Прием команд:** получает текстовые инструкции от пользователя и передает их системе на исполнение.
- **Запуск программ:** управляет запуском и остановкой приложений и процессов.
- **Автоматизация задач:** работает как язык программирования, позволяя писать сценарии (скрипты) из набора команд с условиями и циклами.
- **Перенаправление потоков:** умеет перенаправлять ввод и вывод данных между программами.

#### Популярные виды Shell
- **Bash (Bourne Again SHell):** стандартная и самая популярная оболочка в дистрибутивах Linux и macOS.
- **Zsh (Z Shell):** продвинутая оболочка с гибкой настройкой (установлена по умолчанию в современных Mac).
- **PowerShell:** современная командная оболочка от Microsoft для Windows, Linux и macOS.
- **Sh (Bourne shell):** классический и самый старый прародитель Unix-оболочек.
