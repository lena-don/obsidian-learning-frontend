**Минификация** — это ==процесс удаления из исходного кода лишних символов без изменения его работы, чтобы уменьшить размер файлов и ускорить загрузку сайтов==. 

#### Что удаляется при минификации
- **Пробелы и табуляция** — нужны для читаемости кода человеком, но не нужны браузеру.
- **Переносы строк** — объединяют код в одну длинную строку.
- **Комментарии** — пояснения разработчиков для себя и коллег.
- **Сокращение имен** — иногда длинные имена переменных заменяются на короткие (например, `totalSum` может превратиться в `t`). 

#### Зачем она нужна
- **Ускорение сайта** — файлы весят меньше, поэтому браузер скачивает их быстрее.
- **Экономия трафика** — снижается нагрузка на сервер и сеть пользователя. 

#### Популярные инструменты
- **UglifyJS** и **Terser** — для JavaScript.
- **CSSNano** и **Clean-CSS** — для CSS.
- **HTMLMinifier** — для HTML.
- Сборщики проектов (Webpack, Vite, Gulp) умеют делать минификацию автоматически при сборке сайта для публикации.
