**Code splitting** (разделение кода) — это ==метод оптимизации веб-приложений, при котором общий файл со скриптами (бандл) разбивается на более мелкие независимые части (чанки), загружаемые по требованию==.

#### Зачем нужен code splitting
- **Ускорение загрузки:** Браузер скачивает только тот код, который нужен для работы текущей страницы или экрана, а не весь объем приложения сразу.
- **Экономия трафика:** Пользователь не тратит время и ресурсы сети на скачивание тяжелых компонентов, которые он может никогда не открыть (например, панели администратора или редких модальных окон). 
- **Улучшение отзывчивости:** Интерфейс быстрее запускается и начинает реагировать на действия пользователя. 

#### Как это работает
- **Динамический импорт:** Основой технологии выступает синтаксис `import()`. В отличие от обычного импорта в начале файла, он возвращает `Promise` и говорит сборщику (например, [Webpack](https://webpack.js.org/) или [Vite](https://vite.dev/)) сформировать под этот модуль отдельный файл. 
- **Разделение по маршрутам:** Самый популярный подход, когда каждая страница сайта (маршрут) загружается только в момент перехода на нее. 
- **Разделение по компонентам:** Отдельные тяжелые элементы (редакторы текста, графики, большие таблицы) подгружаются только тогда, когда пользователь до них доходит.
