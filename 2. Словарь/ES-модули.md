==**ES-модули (ECMAScript modules)** — это официальный стандарт организации и разделения кода на отдельные файлы в JavaScript, использующий ключевые слова `import` и `export`. ==

_ИЛИ:_

==**ES-модули (ECMAScript Modules или ESM)** — это встроенный в язык JavaScript стандарт, который позволяет делить большой код на отдельные изолированные файлы и аккуратно связывать их между собой с помощью команд== `import` и `export`.

*Ecma International — основанная в 1961 году ассоциация, деятельность которой посвящена стандартизации информационных и коммуникационных технологий. Изначально ассоциация называлась ECMA — European Computer Manufacturers Association, однако она сменила название в 1994 году в связи с глобализацией её деятельности. Вследствие этого название Ecma перестало быть аббревиатурой и больше не пишется заглавными буквами.

## Зачем они нужны?
Раньше весь код на JavaScript писался в кучу или подключался через разные теги `<script>`. Все переменные и функции падали в общую «глобальную» кучу, из-за чего имена часто конфликтовали друг с другом.

#### ES-модули решают эту проблему:
- **Изоляция:** У каждого файла-модуля своя личная область видимости. То, что объявлено внутри файла, по умолчанию невидимо снаружи.
- **Порядок:** Чтобы использовать код из другого файла, нужно явно разрешить это (`export`) и явно забрать (`import`).
- **Понятность:** Сразу видно, от каких файлов зависит текущий скрипт.

#### Как это работает на примере
У нас есть файл с математической функцией `math.js`:
```
// math.js — это модуль
export function add(a, b) {
  return a + b;
}
```

А есть главный файл `main.js`, где эта функция нужна:
```
// main.js
import { add } from './math.js';

console.log(add(2, 3)); // 5
```

#### Главные особенности
- **Работают везде:** Современные браузеры и серверная платформа Node.js поддерживают ES-модули «из коробки» (нативно). В браузере такой скрипт подключается с атрибутом `type="module"`: `<script type="module" src="main.js"></script>`.
- **Строгий режим:** Все модули автоматически работают в строгом режиме (`use strict`).
- **Асинхронность:** Браузер загружает модули по очереди и аккуратно, не зависая и не ломая страницу.
