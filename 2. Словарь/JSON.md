**JSON** (JavaScript Object Notation) — это ==простой текстовый формат для хранения и передачи данных==.

[Статья на Википедии](https://ru.wikipedia.org/wiki/JSON)

### Как устроен JSON
- **Пары «ключ — значение»**: Данные записываются как имя поля и его значение.
- **Строки в кавычках**: Ключи всегда берутся в двойные кавычки.
- **Типы данных**: Поддерживает текст, числа, логические значения (`true`/`false`), массивы и другие объекты.
- **Понятен всем**: Формат легко читают и люди, и компьютеры.

Подробнее прочитать о стандарте можно на официальном сайте [JSON](https://www.json.org/json-ru.html). 

### Зачем нужен, чем хорош
- **Обмен данными**: Помогает программам и сайтам отправлять информацию друг другу (например, через [[3.2. Что такое API и REST|REST API]] и [можно также почитать про REST API подробнее на этой статье Хабра](https://habr.com/ru/articles/554274/)).
- **Независимость**: Хотя формат создан на основе JavaScript, его используют в Python, C++, Java и других языках.


### Простой пример JSON

```
{
  "id": 101,
  "name": "Алексей",
  "age": 30,
  "is_active": true,
  "skills": ["Python", "JavaScript", "SQL"],
  "address": {
    "city": "Москва",
    "street": "Ленина"
  },
  "phone": null
}
```

#### Основные элементы
- **Объект (`{}`)**: Заключает в себе пары «ключ-значение». Ключи всегда пишутся в двойных кавычках.
- **Массив (`[]`)**: Упорядоченный список элементов, разделенных запятыми.
- **Типы данных**: Строки, числа, логические значения (`true`/`false`) и пустое значение (`null`)
