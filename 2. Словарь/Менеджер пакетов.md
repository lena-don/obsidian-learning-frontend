==**Менеджер пакетов** — это инструмент для автоматической установки, обновления, удаления и управления сторонними библиотеками и зависимостями в проекте.==

#### Зачем нужен менеджер пакетов
- **Экономия времени:** Позволяет не писать весь код с нуля, а подключать готовые чужие решения.
- **Контроль зависимостей:** Сам скачивает все нужные вспомогательные файлы (зависимости), если для работы библиотеки требуется что-то еще.
- **Удобные обновления:** Позволяет обновить все компоненты программы одной командой.
- **Изоляция:** Помогает настраивать версии библиотек так, чтобы они не конфликтовали друг с другом.

Примеры популярных менеджеров
- **npm / yarn / pnpm** — для JavaScript и Node.js.
- **pip** — для языка Python.
- **Composer** — для PHP.
- **Cargo** — для Rust.
- **Maven / Gradle** — для Java.
