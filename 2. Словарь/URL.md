**URL** (Uniform Resource Locator унифицированный указатель ресурса) — это ==уникальный адрес конкретного файла, страницы или ресурса в интернете==.

#### Что такое URL
- Это точный путь к странице, картинке или документу в сети.
- Пользователи вводят его в адресную строку браузера, чтобы открыть нужный сайт.
- Полное определение термина и детали можно изучить на [MDN Web Docs](https://www.google.com/goto?url=CAESlQEB6zswFUZY66_tb9ERnrixRaAxAeRRoXN4-do1aIJrepZ7V69TWi4GoQVhtDLxW7Im-FnXUmE80VHnPdY54cEcjnU-EI7iF03jDu9uKhBnrAJpZXIQJnFtESKaBLuwyY6_JiyjR_mvIK04dZC4j-GCYNmPBdeKzVkpuZ-iM4bWM85rD4_2uMBVgc9rB8fW3pGIKFvrqQ). 

## Из чего он состоит

- **Протокол (схема):** `https://` — способ передачи данных (например, безопасный `https` или стандартный `http`).

- **Поддомен:** `shop.` — дополнительная часть домена, указывающая на конкретный раздел сайта (например, магазин или форум).

- **Доменное имя (корневой домен):** `example.com` — адрес сайта, состоящий из имени второго уровня (`example`) и зоны (`.com`).

- **Порт:** `:443` — сетевой порт для подключения к серверу (обычно скрыт в браузере, так как подставляется автоматически по умолчанию для http/https).

- **Путь к ресурсу:** `/catalog/phones/item` — точное расположение страницы или файла на сервере.

- **Параметры запроса (строка запроса):** `?id=123&color=black` — передаваемые на сервер дополнительные данные и настройки, начинающиеся с знака вопроса `?`.

- **Якорь (фрагмент):** `#reviews` — метка для перехода к конкретной части (секции) на странице, которая начинается с решетки `#`.

### Как устроен URL query
- **Знак вопроса (`?`):** отделяет основной адрес страницы от параметров.
- **Пары «ключ = значение»:** передают конкретные данные (например, `search=laptop`).
- **Амперсанд (`&`):** разделяет несколько параметров между собой, если их больше одного (например, `?search=laptop&sort=price`).
	Пример ссылки с query-строкой:  
	`https://example.com`  
	Здесь `category=shoes` и `color=red` — это параметры запроса.

#### Для чего нужны URL query
- **Фильтрация и сортировка:** выбор нужных товаров в интернет-магазинах (по цвету, цене, размеру).
- **Поиск:** передача поискового запроса на сервер (например, `?q=python`).
- **Аналитика:** отслеживание переходов по рекламным меткам (например, UTM-меткам
