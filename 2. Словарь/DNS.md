**DNS-сервер** (Domain name server сервер доменных имен) — ==это специальный компьютер или программа, которые переводят понятные людям текстовые адреса сайтов (например, `google.com`) в понятные компьютеру цифровые IP-адреса (например, `8.8.8.8`)==
