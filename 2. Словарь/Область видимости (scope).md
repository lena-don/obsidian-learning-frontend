==**Область видимости (scope)** в программировании — это часть кода, в которой переменная или функция доступна для использования==.

#### Основные виды областей видимости
- **Локальная (Local):** Переменная видна только внутри конкретной функции, метода или блока кода, где она создана. За пределами этого блока она недоступна.
- **Глобальная (Global):** Переменная объявлена вне всех функций и классов. Она доступна из любой точки программы. 
- **Модульная / Пространство имен (Module / Namespace):** Переменные доступны в пределах одного файла или модуля (например, в Python или JavaScript).

#### Зачем нужна область видимости
- **Защита данных:** Изоляция переменных предотвращает их случайное изменение из других частей программы.
- **Устранение конфликтов:** Позволяет использовать одинаковые имена переменных (например, `count` или `i`) в разных функциях, не боясь их пересечения.
- **Оптимизация памяти:** Переменные удаляются из памяти (время жизни), когда программа выходит за пределы их видимости.
