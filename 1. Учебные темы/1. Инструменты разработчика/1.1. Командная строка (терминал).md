**Флаги в терминале** — это специальные символы или слова, которые добавляются после команды для изменения её поведения или настройки

##### Как устроены флаги:
- **Обозначение:** Обычно начинаются с одного дефиса и буквы (например, `-a`) либо с двух дефисов и слова для полных названий (например, `--all`).
- **Роль:** Они работают как переключатели «вкл/выкл» или задают конкретные настройки для выполнения программы.
- **Объединение:** Короткие флаги часто можно объединять вместе, записывая их после одного дефиса (например, вместо `-l -a` написать `-la`).

##### Примеры использования
- **Команда `ls`:** Отображает список файлов. Флаг `-l` показывает подробную информацию в виде таблицы, а флаг `-a` добавляет скрытые файлы. Вместе они пишутся как `ls -la`.
- **Из моего учебного проекта по Реакту**: `npm run dev -w 03-rendering`
	- **`npm`** — это **пакетный менеджер** для Node.js (Node Package Manager). Он управляет библиотеками, зависимостями и запускает встроенные скрипты проекта.
	- **`run`** — встроенная **команда npm**, которая указывает, что нужно выполнить пользовательский скрипт, описанный в файле `package.json`.
	- **`dev`** — **название скрипта**, который мы хотим запустить. Обычно внутри него прописана команда для старта локального сервера разработки (например, через Vite, Next.js или Webpack).
	- **`-w`** — это **флаг** (сокращение от `--workspace`), который указывает npm, что команду нужно выполнить внутри определенного рабочего пространства (папки в монорепозитории).
	- **`03-rendering`** — **значение флага** `-w`. Это имя конкретной папки-урока, в которой лежит свой `package.json` со своим скриптом `dev`. 


#### Популярные флаги для команды `ls` (просмотр файлов)
- **`-a` (all)**: Показывает все файлы, включая скрытые (начинающиеся с точки).
- **`-l` (long)**: Включает подробный список (размер, дата, права доступа).
- **`-h` (human-readable)**: Показывает размеры файлов в удобном виде (КБ, МБ, ГБ) вместе с `-l`.
- **`-r` (reverse)**: Меняет порядок сортировки на противоположный.
- **`-t` (time)**: Сортирует файлы по времени изменения (самые новые сверху). 

#### Общие полезные флаги
- **`-R` (recursive)**: Применяет команду рекурсивно — ко всем вложенным папкам и файлам (например, в `cp -R` или `rm -R`).
- **`-f` (force)**: Принудительное выполнение без запроса подтверждения (например, в `rm -f`).
- **`-i` (interactive)**: Запрашивает подтверждение перед каждым опасным действием (например, удалением).
